Run a node

Validator guide

Everything to take an Impetus node from zero to an elected validator. Follow top to bottom.

Before you start
  • Canary network — you need a reachable public bootnode to peer from outside.
  • Active set capped at 32, elected by stake each era. Registering ≠ elected.
  • Validators can be slashed for equivocation or downtime.

1Run a node

Start a validator node against the canonical chain spec and warp-sync to the finalized head. Keep the unsafe RPC on localhost.

# Docker — RPC bound to localhost (unsafe methods needed next)
docker run -d --name impetus-validator --restart unless-stopped \
  -p 127.0.0.1:9944:9944 -p 30333:30333 -v impetus-data:/data \
  -v "$PWD/impetus.json:/spec.json:ro" \
  --entrypoint impetus-node tranhuyduan/impetus-railway:v0.3.0 \
  --base-path /data --chain /spec.json --validator --sync warp \
  --rpc-methods unsafe --bootnodes "<PUBLIC_BOOTNODE>"

Or run the repo helper: SPEC=./impetus.json ROLE=validator apps/node/scripts/run-node.sh

2Generate session keys

Ask the node for a fresh key bundle. Copy the result 0x value for step 4.

curl -s -H 'Content-Type: application/json' \
  -d '{"id":1,"jsonrpc":"2.0","method":"author_rotateKeys","params":[]}' \
  http://127.0.0.1:9944
# => {"result":"0x<256 hex chars>"}
