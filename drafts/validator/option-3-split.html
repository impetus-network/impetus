Become a validator

Read the steps on the left; do the on-chain actions on the right. The console tracks your progress.

01

Run & sync a node

Warp-sync a validator node against the canonical spec. Keep unsafe RPC on localhost.

# docker run … --validator --sync warp --rpc-methods unsafe
docker logs -f impetus-validator
02

Generate session keys

Ask the node for a fresh 128-byte bundle; copy the 0x result for the console →.

curl … '{"method":"author_rotateKeys"}' http://127.0.0.1:9944
03

Bond your stake on-chain

Bond ≥ 1,000 IPT from the stash you will validate with. Use the Staking page, then return.

04

Register session keys on-chain

Submit the bundle via Session (0x0818) — see the console panel.

05

Start validating on-chain

Declare intent + commission via Staking (0x0810).

06

Get elected

The next era picks the top validators by stake. Stay online and keep keys current.
